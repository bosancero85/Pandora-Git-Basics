So startest du

  1. Datei für dein System herunterladen.
  2. Starten – unter Linux zuerst chmod +x Pandora-Git-Basics-Linux.AppImage ausführen.
  3. Kategorie wählen oder suchen, Befehl mit dem Copy-Knopf übernehmen und im Terminal einfügen. Die Sprache stellst du in der Seitenleiste unter „Einstellungen“ ein.

Hinweise: Die Programme sind nicht signiert. Windows zeigt ggf. eine SmartScreen-Meldung („Weitere Informationen“ → „Trotzdem ausführen“), manche Virenscanner lösen bei selbst gebauten EXE-Dateien einen Fehlalarm aus; macOS verlangt beim ersten Start Rechtsklick → „Öffnen“. Bei Ubuntu ab 22.04 braucht ein AppImage ggf. sudo apt install libfuse2. Der Befehlskatalog ist auf Deutsch und Englisch vollständig; in den übrigen Sprachen ist die Oberfläche übersetzt, Befehlstexte erscheinen dort auf Deutsch.

Aus dem Quellcode starten

Für andere Systeme oder zum Ausprobieren – benötigt Python 3.10 oder neuer und PyQt6 (der Ordner language_plugin muss neben dem Programm liegen):

git clone https://github.com/bosancero85/Pandora-Git-Basics.git
cd Pandora-Git-Basics
pip install -r requirements.txt
python pandora_git_basics.py
